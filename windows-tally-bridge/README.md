# DS Distributor Tally Bridge — Windows Installer for Tally ERP 9

Production-grade Windows background service connecting local **Tally ERP 9** / **TallyPrime** installations with the **DS Distributor** cloud platform on Render via secure outbound HTTPS.

## 2. Security & Compliance Guarantees

1. **Zero Public Port Exposure**: Local port `9000` is **NEVER** opened to the public internet or external firewalls. The office workstation initiates all traffic via outbound HTTPS connections on port `443`.
2. **Strict Loopback Binding**: The bridge communicates **only** with `127.0.0.1` / `localhost`. All other IP ranges, WAN destinations, and internal subnets are blocked at the code level.
3. **One-Time Pairing Workflow**: Pairings require a temporary 15-minute one-time code (`BRG-PAIR-XXXX-XXXX`) generated by a authorized `SUPER_ADMIN` or `OFFICE_ADMIN`.
4. **Revocable Device Identity**: Administrators can revoke paired devices with one click in the Back Office console, terminating access immediately.
5. **HMAC-SHA256 Command Signing**: Every cloud command is signed using the bridge's shared secret key. Unsigned or tampered commands are dropped.
6. **Replay & Expiry Protection**: Each command contains a cryptographic nonce and a 60-second expiration timestamp. Replayed or delayed commands are rejected.
7. **Strictly Read-Only Allowlist**:
   - `TEST_CONNECTION`
   - `LIST_COMPANIES`
   - `GET_STOCK_SUMMARY`
   - `GET_PRODUCT_PRICES`
   - `GET_CUSTOMER_LEDGERS`
   - `GET_RECEIPT_VOUCHERS`
   - **Zero Voucher Creation**: All receipt export, payment export, journal voucher, and accounting write operations are strictly prohibited in bridge transport mode.
8. **Company Match Enforcement**: Before returning inventory, batch, or customer ledger data, the bridge verifies that the active loaded company in Tally matches the target company name (`"A2Z Diagnostic Services India Pvt Ltd"`). If the user opens a different company, data is withheld.
9. **Zero Shell Command Execution**: The bridge does not accept or execute any operating system shell commands.
10. **Redacted Logs**: Credentials, tokens, and device secrets are scrubbed (`***REDACTED***`) before writing to disk or console.

## 3. Prerequisites

- **Operating System**: Windows 10, Windows 11, or Windows Server 2016+
- **Accounting Software**: Tally ERP 9 (Rel 6.x+) or TallyPrime (1.0 - 5.x)
- **Tally Configuration**:
  - Open Tally -> Press **F12** -> **Advanced Configuration**
  - Set **Tally is acting as**: `Both` or `Server`
  - Set **Enable ODBC**: `Yes`
  - Set **Port**: `9000`
  - Restart Tally
- **Runtime**: Node.js 18.x or higher installed on the office PC ([Download LTS](https://nodejs.org/))

## 4. Installation & Pairing Guide

### Step 1: Generate Pairing Key in DS Distributor
1. Log in to the DS Distributor Back Office as `SUPER_ADMIN` or `OFFICE_ADMIN`.
2. Open **Tally Integration & Sync Manager** -> Click **Bridge Pairing & Devices**.
3. Click **Generate 15-Minute Pairing Key**.
4. Copy the generated key (e.g., `BRG-PAIR-8491-9231`).

### Step 2: Run Setup Wizard on Office Workstation
1. Open the `windows-tally-bridge` directory on the office PC.
2. Double-click `setup-bridge.bat` (or run in PowerShell):
   ```powershell
   .\setup-bridge.bat
   ```
3. Enter your DS Distributor Render backend URL:
   ```
   https://diagnostic-services.onrender.com
   ```
4. Enter the 15-Minute Pairing Key.
5. The wizard verifies local Tally at `http://127.0.0.1:9000/` and securely saves `config.json`.

## 5. Running the Bridge

### Option A: Interactive Console (Recommended for Initial Testing)
Run `run-bridge.bat`:
```cmd
run-bridge.bat
```
You will see live polling indicators, company verification status, and command execution latency.

### Option B: Windows Background Service (Recommended for Production)
Open PowerShell as Administrator and run:
```powershell
powershell -ExecutionPolicy Bypass -File .\install-service.ps1
```
- Installs the task in **Windows Task Scheduler** (`DSDistributorTallyBridge`).
- Automatically starts on system boot.
- Restarts automatically within 1 minute if terminated or failed.
- Appends logs to `logs\bridge_service.log`.

---

## 6. Uninstallation & Revocation

### Step 1: Remove Windows Background Service
Open PowerShell and run:
```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall-service.ps1
```
This stops the background process and deletes the Scheduled Task.

### Step 2: Revoke Device Identity in DS Distributor
In DS Distributor Back Office -> **Tally Integration** -> **Bridge Devices**:
Click **Revoke** next to the workstation. The bridge can no longer poll or submit data.

## 7. Troubleshooting

| Symptom | Cause | Solution |
| :--- | :--- | :--- |
| `Local Tally ERP 9 is unreachable` | Tally is closed or HTTP server is disabled | Open Tally. Press F12 -> Advanced Configuration -> Enable ODBC/Server on port 9000. |
| `Company Mismatch` | Wrong company is loaded in Tally | Press Alt+F1 in Tally and select the configured target company (`A2Z Diagnostic Services India Pvt Ltd`). |
| `Pairing Key Expired` | Pairing key was generated >15 minutes ago | Generate a fresh pairing key in DS Distributor Back Office. |
| `Bridge Device identity rejected` | Device was revoked in Back Office | Re-run `setup-bridge.bat` with a newly generated pairing key. |
